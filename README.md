# QA-ASD-STE100

Installers and updates for QA-ASD-STE100.

**To install:** open [Releases](https://github.com/beniaminzotescu/qa-automation-tool-releases/releases/latest), download `QA-ASD-STE100-Setup-<version>.exe` and run it. It downloads and installs the app. Installed apps update themselves.

The installer is not code-signed yet: if Windows shows "Windows protected your PC", click **More info** then **Run anyway**.
